# Dark Sky 4.3.4 — Muster Roll Architecture Note

Command Find remains read-only in Captain's Quarters. Navigation crosses into the Engine only through the existing authorized command route. Order search and order targeting both resolve against `getMergedOrders()` and canonical Project IDs. The project Orders renderer remains authoritative for approved active/completed/archive rows. Retained records that are intentionally searchable but not part of the approved project roll are displayed in a temporary read-only Historical Order Detail block; they are never promoted into active orders or made mutable by the Captain route.
