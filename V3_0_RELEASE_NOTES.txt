BLACK FLAG ENGINE v3.0
STRUCTURAL MILESTONE RELEASE

V3.0 is a platform refit rather than a visual-only release.

FOUNDATION
- Schema v3 project envelopes
- Permanent per-project namespaces
- Default-deny isolation metadata
- Central role and permission policy
- Formal lifecycle model: Draft → Configured → Owner Invited → Owner Active →
  Deployment Ready / Testing → Live → Suspended / Relationship Ended / Archived
- V3 audit foundation
- Recovery snapshots and 2.9.x migration
- Structural integrity service

MACHINERY
- Owner Portal module access is checked against v3 project/role policy
- Owner order reads and order-status changes are project scoped
- Orders, customers and ledger entries carry v3 namespace/isolation metadata
- Kiosk/deployment records carry device-only authorization metadata
- Engine Revenue / Profit / Usage / Cost feed the v3 telemetry service
- Captain business-relationship decisions are explicit governance audit events

IMPORTANT PRODUCTION BOUNDARY
V3.0 now has the client-side identity, project-boundary and authorization architecture,
but real outside-owner production authentication is intentionally NOT claimed complete.
Before production owner rollout, Black Flag still requires server-backed identity,
secure sessions, server-side authorization, password recovery and revocation.
