# Quartermaster · 8.8.20.51

## Install — three steps

1. Extract the new .51 upload ZIP and open its matching folder.
2. Upload every file inside it to the root of the existing GitHub repository over complete Quartermaster 8.8.20.50. Replace matching names and retain all other files.
3. When the site finishes updating, reopen it and confirm **8.8.20.51 · QUARTERMASTER** in the Engine Room. Open **QUOTES & INVOICES** as usual.

This is a visual refinement. The Admiral entry has shorter instructions and clearer progress. The workspace has distinct selected tabs, teal primary actions, quieter secondary buttons, a compact header and more useful space on a short screen. Session/security details and storage details are available through their labeled disclosures. Touch and keyboard navigation remain available.

Your .50 catalogs, drafts and finalized documents remain in the same device storage. There is no data migration, browser-data reset, SQL update or permission change. Keep using **Business & backup** for private backup files; records still do not synchronize between devices.

The approved HouseHull example is under **Overview → Create example quote**. Existing document layout, numbering, calculations, tax review and PDF generation are preserved. This release adds no ScheduleJoe job handoff or cloud invoice registry.

See QUARTERMASTER_POLISH_VALIDATION.md for the scoped checks and limits. The native iPad/Safari appearance of .51 remains a device observation; offline Chromium checks do not certify physical keyboard or server behavior.
