# Woodwright 8.8.20.39 TEST — photo-fit repair

## Before
Wayfinder's broad warm-color mask accepted a beige countertop point as wood. Its expanded fitting band then covered counter. The DOM preview and flattened artifact independently positioned browser font text, and Review readiness depended on text/style rather than fit evidence.

## Repair
`woodwright_fit.js` detects a contrasting connected wood candidate, keeps open cutouts/bright holes, fills enclosed dark-painted gaps, erodes the candidate for a clearance inset, and finds an all-inside rectangle. There is no broad full-photo/contour fallback when evidence is weak. Detection is bounded, image-relative, and needs visual confirmation. It is NOT a calibrated length, species classifier, or CNC model.

The selected A/B companion profile is rasterized with its existing scale and spacing. Actual visible pixels, including the stroke, are measured. A uniform fit places that complete sprite inside the inset rectangle and a final alpha-pixel check rejects pixels outside the candidate. No clipping mask hides spillover. The live layer and the review composite come from the same canvas render; the review step never fits the word again.

Ike's design now shows a cyan proposed lettering area and an explicit visual-area checkbox. Size, species, area review and manufacturing authority remain different decisions. Changes of photo/project clear transient fit state. Changes of wording/style/finish invalidate prior approval; old asynchronous rendering cannot replace newer work. Blank wording produces no new lettering. Unsupported profiles and missing fit runtime fail closed.

A captured source image is bound before asynchronous analysis can publish its result. Temporary scene masks and canvases are not written to localStorage or the order store. Headway's existing preview packet, source photo preservation, separate approval time, scoped hashing and once-only save contract remain in use. Production/Sea Trial activation remains held and no real endpoint is added.

The original older detector, layout code and artifact renderer remain named legacy reference helpers, but are not a new-order fallback. No historical order, logo, reference image, geometry pack, SQL or HouseHull plan is changed. Fleet Compass search guards, shared backup codec and all account boundaries retain existing behavior.

## Test boundaries
Pure mask tests cover warm scenes, actual synthetic board interiors, cutouts, empty/invalid data, rotated bands, visible-pixel spill, exact source preservation and absence of storage calls. Current browser tests execute the actual design handlers, updateUi, rendering, area review, artifact staging and acceptance functions with shipped HTML/CSS and synthetic auth/stock/storage boundaries. They test the screenshot-derived example, long/mixed-case wording, rotations, blank/reset/replacement, latest-render behavior, no production admission and viewport correspondence.

The diagnostic photograph is extracted from a supplied screenshot, NOT the original camera file. Its bytes are NOT put in the public upload. Default browser replay uses a synthetic board; an optional local photo argument enables the documented reproduction. Native Safari and the user's actual original-photo behavior require field acceptance.

## Unresolved separately
Site-storage quota, residual owner navigation scroll/session issues, Mission Control status reconciliation, actual database restore/cloud durability, server-authorized stock/species decisions, and manufacturing glyph certification are not declared fixed by this release. The visual-area checkbox never grants an owner/Captain/Admiral role. Do not clear browser data to force any test through.
