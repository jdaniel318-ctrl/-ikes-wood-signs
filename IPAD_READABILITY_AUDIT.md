# v3.8.10 — iPad Readability Refit Audit

## Mission
Improve Project Control readability on iPad without changing navigation, identity, authorization, or project behavior.

## Changed
- Raised the minimum size of supporting labels, helper text, KPI captions, alert details, activity metadata, identity values, Quick Action text, and order metadata.
- Increased primary and secondary command label size.
- Added modest vertical space to touch layouts to protect scanability and finger targets.

## Preserved
- Two-level Project Control navigation.
- Mission-critical Black Flag navigation.
- Immutable project identity and rename behavior.
- Project isolation and authorization.
- Fleet Health and Project Control functionality.

## Principle
Dark Sky command surfaces should remain readable at normal iPad viewing distance without forcing the operator to lean in or zoom.
