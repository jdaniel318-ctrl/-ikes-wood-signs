Goal: support an index card carrying customer contact details during Sightline's temporary photo measurement trial. Card-free capture remains the product goal.
Architecture: keep calibrated-photo and native ARKit measurements independent. Photo calibration accepts a named, fixed-size reference; evidence records its exact dimensions. Public proof pixels cover the reference, while a clearly labelled private job download retains the capture for Ike.
Tech stack: existing browser JavaScript, canvas, shared Carvewright geometry, existing release packager.
Spec: user approved an index-card bridge, prefers eventual card-free photo/sweep measurement, and wants customer information written on the card.

Global constraints: no backend, authentication, production orders or native app changes; no OCR, species or machining accuracy claims; no rack code entry; native capture must not acquire a card dependency. Contact details stay inside the card. The private download is not encrypted and is not a public proof.
Review focus: wrong scale after card-size changes; raw customer pixels embedded in a supposedly clean proof; stale downloads; unbounded or invalid references; accidental native card requirement; broken SVG image rendering.
