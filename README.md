# Dark Sky 4.3.2 — Close Aboard

Close Aboard turns Command Find results into useful navigation instead of a dead-end list. Project, order, and customer result cards are now tappable and expose clear actions. Order results route into the owning project's Engine order command and highlight the selected order after Engine authorization. Broad searches show a short useful subset first with explicit Show All / Show Less controls, reducing long iPad scrolls. Search remains read-only in Captain's Quarters; opening a result crosses into Engine machinery through the existing Engine authorization boundary. The commissioned V4 hull, four admitted project identities, project isolation, Storage Steward, Black Box, quarantine protections, and Captain Lab boundary remain unchanged.
