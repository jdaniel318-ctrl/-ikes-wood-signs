# Dark Sky 4.3.8 — Fleet Marks

Fleet Marks makes Project Command reuse each vessel's own project graphics instead of showing initials whenever a suitable project-owned mark is already available. The fleet identity order is Project Logo / Mark, then project Hero Graphic, then project Footer Graphic, with branded initials only as the final fallback. Ike's established customer artwork is retained as a project-specific compatibility mark until a dedicated Project Logo / Mark is assigned.

No project data, orders, admissions, graphics, quarantine evidence, or security boundaries are changed by this release.
