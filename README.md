# Dark Sky 4.3.4 — Muster Roll

Muster Roll completes the Captain Command Find → Engine order handoff. Search results now classify order lifecycle as Active, Completed, Archived, or Historical. The same canonical merged order source is used for search and exact-target navigation. Active/archived orders open in their normal project roll; retained historical or legacy orders open as a read-only Historical Order Detail instead of silently landing at the top of an unrelated list. Exact targets are scrolled into view and highlighted. The commissioned V4 hull, project isolation, admissions, quarantine, storage steward, and Captain/Engine authorization boundary are unchanged.
