# Dark Sky 4.3.3 — Boarding Party

Boarding Party hardens the Command Find handoff from Captain's Quarters into Engine project/order views. Captain result actions now call a direct global command route, close Captain overlays before Engine navigation, preserve the Engine authorization gate, carry canonical project and order IDs explicitly, and visibly highlight the selected order. Failed routes now surface on-screen and in Black Box instead of failing silently. The commissioned V4 hull and project data model are unchanged.
