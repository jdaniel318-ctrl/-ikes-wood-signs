# Dark Sky 4.3.5 — Exact Bearing

Exact Bearing fixes the final Command Find → Project Orders targeting gap. The selected order ID is now carried into the Project Orders renderer itself. If the target belongs to the approved project roll, that exact card is highlighted and scrolled into view. If the target is a retained historical/legacy order outside the active approved roll, a read-only Historical Order Detail is rendered above the current roll and focused directly. Search, routing, and the Project Orders renderer now resolve the same canonical merged-order source. No historical order is promoted back into active work.

The commissioned V4 hull, project isolation, admissions, quarantine, Storage Steward, Black Box, and Captain/Engine authorization boundaries are unchanged.
