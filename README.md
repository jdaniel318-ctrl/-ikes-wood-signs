# Workshop Engine v2.9.77 — Engine-Wide Visual System

This release extends the approved Modern Ship Engine Room language through the entire Business Mode Engine.

## What changed
- Project Control Center is now a dark modern vessel-console environment.
- All project tabs inherit the Engine visual system instead of falling back to white/cream cards.
- Marketing & Brand, Graphics Library, Products, Customer Experience, Deployment, Owner Access, AI, Workflow, Publishing, Orders, Ledger, Payments, Permissions, Customers, and Notifications use the same dark steel/navy control language.
- Inputs, selectors, cards, rows, ledgers, graphics tools, deployment tools, and status panels were harmonized.
- The modern Engine benchmark is used as a subtle environmental texture in project control surfaces.
- Artwork/logo previews can remain light so the actual project artwork is not visually altered.
- Business Mode copy in Marketing no longer says “Dark Flag”; it uses “the Engine.”
- Pirate Mode remains a separate presentation mode and was not redesigned by this pass.

## Asset inspiration
Business Mode uses the two existing Engine assets as design references:
- `engine_room_modern_benchmark_v2976.png` — direct modern vessel bridge inspiration and subtle background texture.
- `engine_room_benchmark_v2955.jpg` — reference for dense framed control hierarchy only; pirate imagery is not carried into Business Mode.

## Assets
No assets added, removed, renamed, or modified in this pass.
