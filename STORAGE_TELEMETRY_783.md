# Storage & Telemetry — 7.8.3

Harbor Exit Safe Cleanup Acknowledgement makes the cleanup control use a direct iPad-safe activation path. The first tap only arms cleanup and must visibly change the control to `CONFIRM SAFE CLEANUP` plus a `CLEANUP ARMED` status. The second tap performs stale-cache-only cleanup and re-sounds storage. Protected project, order, customer, graphics, settings, recovery, admissions, and quarantine records are never cleanup targets.
