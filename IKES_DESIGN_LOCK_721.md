# Ike's Design Lock 7.2.1 — Approved Artifact Integrity

The customer-approved sign image becomes immutable when **APPROVE MY DESIGN** is pressed. Final review, confirmation, admin and archive consume that same locked preview instead of re-running the layout engine. Any edit invalidates the lock and requires fresh approval.

The order stores the approved render metadata, recognition state, usable lettering region, line wrapping strategy and a lightweight integrity hash. Fleet Proving Ground adds an **Approved Artifact Voyage** so future visual-order vessels can inherit this safety contract only after evidence.
