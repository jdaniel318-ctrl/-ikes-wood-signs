## Failures, limitations and open work
Full local HTTP startup was attempted once and failed at the seed page with `net::ERR_BLOCKED_BY_ADMINISTRATOR`, before the application booted. It was not bypassed and is NOT included among passing scenarios. Native WebKit/iPad/iPhone and full hosted startup remain field checks. Two early UI runner processes were interrupted by tool timeouts; neither partial run was counted. The final complete 23-case run passed. Intermediate checksum failures were resolved by correct release stamping/sealing, not by dropping assertions.

Review was inline diff/source review plus automated tests; no independent reviewer agent was available. No claim is made to recognize every wood/background combination. Pale/low-contrast wood or multiple similarly colored objects can hold fitting. Enclosed dark paint is included; a dark void can resemble paint, so the outlined region must be visually checked. The algorithm does not classify knots or prove mechanical clearance. An inset rectangle is deliberately conservative and may use less of an irregular or rotated board.

The site-storage quota error, owner scroll/session continuity, Mission Control status reconciliation, database restore/cloud durability, actual stock authorization and manufacturing geometry are separate open issues.
