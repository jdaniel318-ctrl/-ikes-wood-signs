# Keydeck 8.8.20.95

Install over Freeboard 8.8.20.94.

1. Extract **DarkSky882095-Keydeck-Upload.zip**. Open its folder, upload the contents to the existing repository root, replace matching files, and commit. Keep the other files.
2. When Pages finishes, open the Engine in a fresh Safari tab. The Engine PIN screen should now show number buttons. Enter your usual PIN there, tap **Enter Engine Room**, and check for **8.8.20.95 · KEYDECK**.
3. Choose **Operate Vessels → Legacy Plumbing → Test Center → Open Private Preview**. The test passes if the Legacy homepage opens without Safari offering to save the PIN. If the dialog appears, tap **Not Now** and note which tap brought it up. No test request or customer details are needed.

The change covers both local Engine PIN entrances. A number tap or physical number key updates a row of dots. Clear erases the whole entry and Delete removes its last digit. The existing Engine verifier still checks the code. Contractor sign-in continues to use the contractor’s own account.

The full backup contains application source. To return to Freeboard, extract **DarkSky882094-RollbackFrom882095.zip** and put its files in the same repository root. Keep browser storage and business records in place.
