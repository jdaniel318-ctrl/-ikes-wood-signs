# Black Flag 8.8.20.36 — Headway TEST architecture

Baseline: all 133 files from Keelmark 8.8.20.35 are retained. Existing static HTML/JS, canonical vessel identities, namespaces, auth, A/B geometry, original artwork and server contracts remain the platform. There is no new backend or external dependency in this release.

- fleet_viewport.js/css: scoped layout and explicit navigation epochs. Fresh screens start at their top; intentional Back uses stored list position. Inputs, resize, repaint and session rechecks do not force a top reset. Sticky identity and preview-banner overlap are removed on the Ike customer route. Image grid minimum dimensions are explicitly bounded so a shorter card contains rather than crops the photo.
- headway_contracts.js: pure draft/decision/approval/media integrity, once-only test-storage transaction, exact-vessel backup/rehearsal interfaces. SHA-256 native and fallback tested against Node vectors. Hashes are consistency checks, not signatures or proof of authorized ownership.
- app.js: original customer renderer and approval artifact functions remain; Headway adds nominal decision gates, frozen draft/preview fingerprints, actual acceptance time and original-photo lineage. Private Preview uses explicit sample 2 ft and Cedar decisions. Neither heuristic agreement nor caller-supplied owner flags can activate real size/species decisions. Real/Sea Trial activation is deliberately held because no reviewed owner service is established here.
- owner.html/business_deck.js: original exact-owner guards and business record source retained. New backup buttons export full exact-business rows and rehearse only in a temporary Map, never against the original database. New job fields are read additively; legacy gaps stay gaps. Real source data is not migrated.

A new valid test job freezes the app-resolution source, original lineage, rotated display source, approved composite, exact text/style, price/rule basis, separate size/wood decisions, generated time and actual acceptance time. Editing a bound field requires a fresh artifact and acceptance. The once-only writer is tested in an isolated store, not wired as a new production endpoint. Unknown/quota outcomes retain the complete packet and offer read-only reconciliation, not automatic retry or photo dropping. Historical generic/historical save functions are retained; this release does not certify all old write paths.

Private preview avoids persistent customer draft/order writes and external messages. Existing Engine preview-review metadata is a separate retained setup path; this release does not certify that opening a Test Deck has no local diagnostic side effects. No simulated customer submission changes live records.

No user accounts, membership, billing, commissioning or publication is changed. The two terminal VoyageKeeper commissioning operations remain closed/retry-forbidden. HouseHull does not inherit Ike’s nominal-size tolerance; Bootstrap Build remains outside Fleet Core.
