# FUN — Admiral-only first playable draft

This is a separate Admiral program. The game stays fictional and outside Fleet Core. First Light is the opening mission title; the real game name remains undecided.

One expedition: salvage a signal lantern, repair the launch, distribute rescue supplies, observe the safe channel, balance the sail and raise the harbor gate. Wrong answers and hints do not remove lives or erase progress. There is a hidden little tern to discover and a choice of pennant at the ending.

The optional Chart Room has six small lessons: fractions, rectangular area, algebra, functions, derivatives and integration. Demonstrations precede independent input beyond algebra. Numeric answers support decimals and fractions; arbitrary code/expressions are never executed. This is a sample of the learning journey, not a complete curriculum or validated educational outcome.

Only the current authenticated Admiral enters through the supported program route. Game code/assets are static public resources, not private DRM. Runtime secrets and business data never enter the scripts-only opaque iframe. Future invited accounts need a separate server-authorized game entrance; the qualifying milestone is unset. Community, chat and multiplayer are not included.

Progress remains in memory and a deliberately downloaded small JSON, not browser localStorage or business stores. An imported game file confers no actual rank or future qualification. Admiral inactivity/session limits are not extended by fictional rewards or forged game messages. No existing business backup is read or overwritten.
