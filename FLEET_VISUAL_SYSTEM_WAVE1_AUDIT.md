# Fleet Visual System — Wave 1 Audit

Release: v3.8.17

## Mission
Wave 1 creates shared visual law for Dark Sky command surfaces instead of continuing one-off white-field fixes.

## Surface hierarchy
- Hull: global dark page background.
- Deck panel: primary administrative/card surface.
- Inset well: embedded data, empty states, and read-only content.
- Interactive field: forms, selectors, and editable controls.
- Intentional light surface: allowed only for proof/artboard/customer-content contexts where light materially improves the task.

## iPad readability
The refit raises the typography and control-size floor for Project Control, Engine command surfaces, and Commissioning without enlarging major headings unnecessarily.

## Empty state rule
Administrative empty states must look complete even when they contain no data. A raw white filler bar is a regression.

## Regression boundary
Wave 1 is CSS/system-token focused. It does not alter project identity, authorization, route wiring, commissioning state transitions, order ownership, deployment sealing, or the horizontal fleet rail.

## Forward law
Future Dark Sky command UI should consume these shared visual surfaces rather than inventing isolated white/dark card styles per feature.
